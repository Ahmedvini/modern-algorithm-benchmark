Regenerate into a fresh directory:

```sh
python3 -B report/generate.py --evidence results/raw/autonomous_completion_20261011T095554571762Z --learned results/processed/learned_rank_20261011T095554571762Z --metrics results/processed/count_memory_20261011T095554571762Z --output report/NEW_REPORT_DIRECTORY
```

`INPUTS_SHA256.json` identifies every summary consumed; `PLOTS.json` records
filters, transformations and units. `RESULT_TABLES.json` preserves numerical
tables. Repeated generation is byte-identical in the retained environment,
including PDFs and PNGs; a different Matplotlib/font version may render differently.
See the raw audit for actual commands, source identities, initial failures and
preservation checks. The additional count/RSS plots are generated by
`report/collect_metrics.py analyze`, separately from all timing runs.
