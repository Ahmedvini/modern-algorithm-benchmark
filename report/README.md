# Reproducible research deliverables

The CPU-only release is [FINAL_REPORT.md](cpu_only_20261011T133332368294Z/FINAL_REPORT.md)
with [a compact PDF](cpu_only_20261011T133332368294Z/REPORT.pdf),
[12-slide PDF](cpu_only_20261011T133332368294Z/PRESENTATION.pdf), and
[slide source](cpu_only_20261011T133332368294Z/PRESENTATION.md).
Seven figures cover sorting, scaling, search, structures, OpenMP, comparisons and
RSS. GPU results are excluded. Earlier assets at
`autonomous_20261011T095554571762Z/` and its `_regenerated` counterpart remain
unchanged historical deliverables; they are not replaced in place.

Regenerate into a fresh directory:

```sh
python3 -B report/generate.py --evidence results/raw/autonomous_completion_20261011T095554571762Z --learned results/processed/learned_rank_20261011T095554571762Z --metrics results/processed/count_memory_20261011T095554571762Z --output report/NEW_REPORT_DIRECTORY
```

Generation first validates summaries against immutable CPU raw observations;
`RAW_VERIFICATION.json` records counts and source environment identities.
`INPUTS_SHA256.json` identifies every summary consumed; `PLOTS.json` records
filters, transformations and units. `RESULT_TABLES.json` preserves numerical
tables. Repeated generation is byte-identical in the retained environment,
including PDFs and PNGs; a different Matplotlib/font version may render differently.
`RENDER_INPUTS_SHA256.json` also binds generator code and copied count/RSS figures.
`verify_cpu.py` blocks subprocess launches during numerical reanalysis; it does
not generate datasets or invoke algorithms. Existing output paths are rejected.
See the [release audit](../results/raw/cpu_only_release_20261011T133332368294Z/FINAL_AUDIT.md)
for actual commands, source identities, initial failures and
preservation checks. The additional count/RSS plots are generated by
`report/collect_metrics.py analyze`, separately from all timing runs.
